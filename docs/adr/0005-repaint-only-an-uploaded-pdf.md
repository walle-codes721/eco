# Repaint only an uploaded PDF

A listener's translated slide is the uploaded PDF with its rows repainted. A talk with no PDF keeps the plain text card in the deck's language, and a talk with no slides shows no slide. The card has no picture and no rows the speaker previewed, so it is left alone.

Translating that card would be a second feature, and it would put words on screen for a talk that never had a designed page.
